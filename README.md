Hola, soy Matias Cena y en este repositorio presento mi Proyecto Final para la certificación en Arquitectura de Flujos de Inteligencia Artificial. La entrega consiste en un Ecosistema de Automatización de IA diseñado para resolver un proceso de negocio sin intervención manual inicial, conectando un orquestador principal en n8n, una base de datos en Notion como memoria del sistema, un motor de procesamiento con modelos IA y un canal de comunicación de salida a través de Gmail y Slack.

El flujo incorpora una lógica con gestión de errores para garantizar la estabilidad ante fallos de API o datos incompletos, junto con un punto de validación humana (Human-in-the-Loop) que requiere aprobación previa antes de ejecutar acciones críticas. Dentro de este repositorio encontrarás la documentación formal del sistema (diagramas de arquitectura, manual de datos, matriz comparativa de costos de IA y políticas de seguridad), el archivo ejecutable .json para importar en n8n, las evidencias de las pruebas de estrés y los enlaces de acceso público al panel de control en Notion, la base de datos y la demostración en video.
